# Java Task Manager

A simple console-based Task Manager built with Java.

## Features
- List all tasks
- Add new tasks
- Update existing tasks (title, description or status)
- Remove tasks

##  Technologies
- Java
- OOP (Object-Oriented Programming)

##  How to run
1. Clone the repository
2. Open in your IDE.
3. Run the `Main.java` file

##  About
Project built for studying Java and OOP concepts like
classes, methods, lists and switch statements.
